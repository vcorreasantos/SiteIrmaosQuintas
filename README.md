🚗 Centro Automotivo Irmãos Quintas - One Page

![MIT License](https://img.shields.io/badge/License-MIT-yellow.svg)

Este projeto consiste no desenvolvimento de uma landing page one-page para o Centro Automotivo Irmãos Quintas,
com o objetivo de melhorar a presença digital da oficina e facilitar o acesso dos clientes às informações e serviços oferecidos.

✨ Objetivo

Criar uma página moderna, acessível e responsiva que aumente a visibilidade da oficina e melhore a experiência do usuário.
